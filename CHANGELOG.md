# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-27

- Initial compatibility rules for Docker Desktop, Podman, OrbStack, and Apple Container.
- Static devcontainer and Compose inspection with optional read-only backend probes.
- Human and versioned JSON reports with CI-oriented exit thresholds.
- Cinematic, accessible product documentation site with a recorded interactive demo.
