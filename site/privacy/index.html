Plain-language policy

Privacy

Effective August 27, 2026

The short version

The CLI works locally. It does not send your project files, configuration, findings, secret names, or usage data to us. This website has no analytics, advertising, cookies, account system, or third-party scripts.

CLI data

Static inspection reads only the devcontainer and Compose files needed for the report. Secret values are not printed. Backend probes happen only when you pass --probe and run read-only local status commands.

Website data

The recorded demo uses fixed example data and does not accept uploads. The service worker may cache public site assets on your device so documentation remains available offline. Clear the site’s storage in your browser to remove that cache.

Hosting logs

Our hosting provider may retain short-lived security logs such as IP address, request path, and user agent. We do not combine them into user profiles or use them for advertising.

Contact

Open a privacy issue in the project’s GitHub repository.
